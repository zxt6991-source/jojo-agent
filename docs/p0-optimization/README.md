## 3. 跨文档统一决策

### 3.1 三种重试必须区分

| 操作 | 执行身份 | 本期规则 |
|---|---|---|
| Provider HTTP attempt 重试 | 同一次模型步骤、同一输入 | 只有尚未发布 ModelEvent 且满足瞬时错误条件时自动重试 |
| 未终止 operation 的恢复 | 原 Run / operation | 使用原执行快照，重新验证当前授权，不自动重放不确定效果 |
| operation 已终止后的用户重试 | 新 Run / operation | 正常提交新任务，不复活旧终态或旧审批 |

三者不能共用一个“从头再跑”实现。自动重试只保证本地工具不会被重复调度，不承诺模型供应商未产生重复计费。

### 3.2 Desktop 与 Server 恢复策略

| Host | P0 默认行为 | 配置或授权不可用时 |
|---|---|---|
| Desktop 现有继续执行路径 | 对仍可恢复的非终态 operation，按 OPT-03 恢复原语义 | 拒绝猜测性恢复；给出明确阻断原因，并提供受控终止路径 |
| Server 启动 | 按 OPT-02 安全终止未完成 operation、释放对应 Lane，再完成业务对账 | 终止不要求解析 Provider、凭据、工具或完整执行快照 |

Server 本期不默认自动恢复旧任务；该行为可避免服务重启时自动产生外部效果。未来如增加显式恢复模式，需要单独的入口、权限与生命周期设计，不能改变已经提交的终态。

### 3.3 持久化顺序

- operation 终态与对应 Lane 解锁使用 Runtime Storage 的同一事务，解锁条件包含预期 operationId。
- App Service 的业务 Run 与 Runtime 可能位于不同数据库；采用可重入对账，不假设跨库原子事务。
- 历史 Run 结果引用该 operation 的完成事实，不能引用 Lane 后续最新的回答。
- execution 快照保持原执行语义；恢复时重新解析当前权限和凭据，不能将快照解释成授权。
- Artifact 的历史 version 仅是已登记更新信息；实际读取 revision 才标识当前所见字节，不能承诺未保存的历史二进制版本。

## 4. 最小交付边界

| 方向 | P0 必须完成 | 后续任务 |
|---|---|---|
| Provider | 完整性检查、取消、错误保真、有界期限与重试 | 部分输出跨 attempt 替换、模型流跨进程续传 |
| Runtime | 安全终止、条件解锁、幂等对账、配置恢复和旧数据处理 | Server 自动续跑、多 Host 同库分布式所有权 |
| Artifact | 当前内容 revision、预览与保存一致性、刷新和兼容 | 二进制历史、相对资源、Range 与大文件性能 |

修复合并时必须同时交付对应测试，不能仅增加“后续补测”的 TODO。旧数据或不确定工具效果需要保留诊断事实，不得为恢复成功率指标强行解锁后重跑。

## 5. 分支与 PR 组织

1. Provider 完成判定可单独提交，后接期限与重试两个变更。
2. OPT-03 先定义 execution schema、持久化与恢复输入映射，再接 Desktop 的缺失配置提示和终止入口。
3. OPT-02 可独立实现 Runtime 安全终止 primitive，随后接入 Server 启动与业务对账；其公共接口与 OPT-03 的恢复入口共同评审。
4. OPT-04 先提交内容一致性 Contract 与 Host 服务，再接入新面板行为，最后验证旧客户端兼容。
5. 四个方向完成各自验证后，统一运行全量检查与受影响的真实 Electron 场景。

不要将大入口拆分、所有性能优化或新文件类型混入上述正确性 PR。必要的小范围抽取以复用状态管理、请求生命周期和内容服务为目的。

## 6. 整体验收

- [x] 空流、截断流、错误流不会变成成功回答或可执行工具批次。
- [x] 重试等待、模型读取和尾部收尾期间取消，均不会产生晚到成功事件。
- [ ] Server 在模型执行、审批和工具效果窗口被强杀后，同一会话最终能够再次运行。
- [ ] 终态提交与业务投影之间再次崩溃，重复启动仍能完成对账且不重放工具。
- [ ] Desktop 恢复保持原 instructions、预算和 actor；缺少可信配置时明确拒绝恢复。
- [ ] 权限收紧、凭据失效和旧审批在恢复后按当前规则处理。
- [ ] Artifact 文件在预览前后、保存请求及保存对话框期间变化，都有确定的一致性行为。
- [ ] 旧会话、旧描述符与既有客户端不会被新增严格 Schema 字段无意破坏。
